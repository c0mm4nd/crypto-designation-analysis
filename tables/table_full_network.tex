\caption{\textbf{Address-level removal test on the complete TRON USDT network.} The entire USDT transfer graph on TRON to 1 January 2025, built from an archival node with no seeding and no sampling: 2.38 billion transfers between 213 million addresses, aggregated to unique directed pairs. Of the 490 addresses named in the seizure orders, 400 appear. The degree-matched row gives the mean and 2.5--97.5 percentile range over 200 draws, with the structural column giving the share of addresses whose whole neighbourhood is removed; the random row is the mean of three. Removing every designated address costs about the same as removing the same number of undesignated addresses of the same degree on the structural measure, where it sits at the 68th percentile of the draws, and more than all of them on throughput, which is what designation selected for. Throughput is value on pairs incident to the removed set and excludes the stranded value, which is reported separately in the last column. Stranded value is not baseline-subtracted: it counts value on pairs off the largest component after the removal without subtracting the value already off it, so each figure is an upper bound. The node's event table holds duplicate rows for re-ingested blocks (2,375,557,775 rows for 2,225,933,042 distinct transfers); the network was rebuilt with them removed, and the designated addresses' incident value now matches their per-address histories exactly. Duplicate rows never created pairs, so every connectivity figure is unchanged from the earlier build; value sums fell by about seven per cent. It strands 590 USDT between surviving addresses, whereas 400 undesignated addresses of the highest degree strand 3.2 billion, 0.022\% of all transferred value.}
