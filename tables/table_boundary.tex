Reading across, the two-hop graph says designated addresses are dispensable and undesignated hubs are not; the one-hop graph says the opposite, in every network. Both are properties of the sampling: in the two-hop graph the hop-2 addresses are mostly degree-one leaves hanging off hop-1 counterparties, and in the one-hop graph every address is present because it transacted with a designated address. The degree-matched control draws undesignated addresses with the same degree distribution as the designated set (mean of three draws) and is the only comparison that holds the sampling fixed. Values are the percentage of the largest weakly connected component lost. These are the values quoted in the main text.
